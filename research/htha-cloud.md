# HTHA + Cloudiness Lesson (Steve Mould IFqI11SIGXo)

## Story
H2 diffuses into steel lattice, steals grain-boundary carbon -> trapped CH4 ->
micro-bubbles -> linked fissures -> explosion. Tesoro Anacortes 2010: steel
under Nelson curve, standard UT said "no reflectors" (correct), missed cloud.

## Takeaway for Argus
Reflector-only detection repeats Anacortes. Need scatter channel:
bubbles << wavelength don't reflect, they scatter (mirrors vs cloudy acrylic).

## Our proxy
- UT air: A_drop_dB, width broaden, A2/A1, inter-pair variance
- Optical: sharpness down, GLCM contrast down
- Gel: Ra/Rz up
- EC: Vpp + phase jitter
Fused to cloud_index 0-100 vs good-coupon baseline.

## Rule
No cal on good coupon = no test. Metallurgy + inspection watch each other.
